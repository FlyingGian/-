# 需求边界与设计决策

本期交付 AshareQuant 1.0.0 研究工作站：原生 PySide6 桌面、按时点数据导入与质量闸门、多因子选股、逐日事件撮合、风险预算、双源行情监控、告警归档回放、报告与 Windows 启动器。默认 500 万、20 只、周调仓。用户授权自主决策，五份设计文档作为实施与验收基线，不额外等待文档审批。

选择：PySide6 而非 Web/Electron，满足纯 Python 和本地桌面；SQLite 元数据 + 分年 Parquet 而非服务器数据库，便于离线与版本快照；自主日频撮合而非直接套用通用回测库，严格约束 A 股规则。

数据边界：首次启动数据库为空，无随机行情或收益注入。CSV 是可审计的完整入口；AkShare 提供普通日线和日历；Tushare Pro 可补充复权、财务、历史成分、状态与现金行动，实际权限取决于账户。缺失历史 ST、历史成分、退市信息或分红时不宣称全市场无偏，严格模式阻止历史研究。真实交易日历必须导入或联网获取，绝不用工作日填充。

实时 3 秒是调度目标，500 只/批、6 并发、1 秒下限。免费源的完整性、稳定性和性能必须在用户网络实测。当前云网络限制与无凭据不等于源不可用；不伪造性能数据。

不包含自动下单、收益保证、Level-2、T+0 股票、行情转售。机器学习提供带 purge 的时序研究接口。没有历史分钟数据时不生成尾盘信号，也不以快照替代历史分钟。

交付分级：实现/自动测试通过/外部实测待完成分别记录。Windows 异常流程做自动化分支测试并提供 CI；Linux 验证不能冒充 Windows 实机。
